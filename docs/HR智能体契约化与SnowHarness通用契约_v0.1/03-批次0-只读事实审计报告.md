## 二、Runner / Session API（批次 2 最小抽离点）

- veADK 直接导出 `Runner`（`veadk/runner.py:468`）：`async def run(messages, user_id="", session_id=..., ...)`，配置 `short_term_memory` 时自动 `create_session`（幂等，存在即复用）；返回最后事件文本。
- 仓库内先例：`tests/eval/test_eval.py:347-368` 已用 `Runner(agent=root_agent, app_name=...) + run_async()`。
- `ShortTermMemory.session_service`（local 后端 → InMemorySessionService）：`agent.py:59-77` 已用它实现 `session_exists()` 与 `context_summary_provider()`。
- **结论**：公共执行门面 `HrAssistantRuntime` 可直接基于 veADK `Runner` 复用现有 root_agent 业务路径，无需复制 Prompt/路由，无需 HTTP 回环。

## 三、内部 A2A 路由

- `DeterministicA2AMiddleware`（`apps/orchestrator/a2a/middleware.py:8-61`）：只拦 `POST /run_sse`；`router.route()` 命中远程路由则直接返回伪造 SSE 事件（author="root_agent"，含 `a2a` 元数据）；未命中/LOCAL 则回放给 AgentKit 原生处理。
- `OrchestratorRemoteRouter`（`apps/orchestrator/a2a/router.py:62-171`）：会话存在性检查、context_summary 拼装与敏感检查、构造 `A2ARequestContext`（caller_agent/locale 固定）、`OfficialA2AClient.invoke`、契约校验、固定失败话术、脱敏日志。
- `DeterministicRouteTable`（`apps/orchestrator/a2a/routing.py:37-68`）：取消/请假/延续 → LOCAL；本人/跨员工数据 → EMPLOYEE_DATA；pending(need_more_information) → 原 target；默认 → CONSULT。
- 本地能力：leave_agent（4 工具）、page_jump、取消/转人工话术均在 Prompt/正则层。

## 四、内部私有合同与安全边界

- `A2ARequestContext`（`packages/agent_runtime/a2a/context.py:32-41`）：`caller_agent` 强制 `^hr_orchestrator`、`locale` 强制 `^zh-CN`、metadata 键集合严格相等校验。
- 敏感字段过滤器（`context.py:19-25`）：拒绝 client_secret / authorization / bearer / runtime_api_key / gaia jwt / ak/sk / employee_id / target_employee_id / corp_id 等；请求侧与响应侧（`contains_sensitive_data`）双向生效。
- `TrustedIdentityResolver`（`apps/employee_data_agent/identity.py:22-58`）：user_id → employee_id（repr 屏蔽）→ 不可逆 `employee_ref`（HMAC-SHA256）；未命中稳定 `identity_unverified`。
- 认证：Runtime API Key 走 `Authorization: Bearer` HTTP Header，不进 A2A 消息体。

## 五、顶层事件模型与流式事实

- 子 Agent 执行器（consult/employee_data）：`new_task` → `start_work` → runtime.run → `add_artifact(TextPart+DataPart)` → 按 status 终态（need_more_information → `requires_input`，即 input-required）。
- 卡片 `streaming=True` 指流式传输通道；执行主流程仍是"运行完成→整块 Artifact"，**内容增量未证明**。
