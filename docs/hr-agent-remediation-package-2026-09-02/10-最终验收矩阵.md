# 最终验收矩阵

## 1. 使用方法

实现完成后逐条验收。

状态只允许：

- PASS
- FAIL
- BLOCKED

Critical 项任何一个不是 PASS，都不能宣布本工程包完成。


```text

- <ID>

```
