# 09 — 回归、安全与最终只读审计

## 1. 双仓回归

### hr-agent-core
至少：
```text
uv sync / 已冻结环境
pytest -m "not eval"
相关A2A / contract / integration
```

有真实模型Key时再跑必要eval；缺Key不伪装成代码失败。

### SnowHarness
至少：
```text
pnpm typecheck
pnpm lint
pnpm build
pnpm test
pnpm architecture:check
pnpm architecture:gate
pnpm test:e2e
```

并跑阶段1定义的数据库/True E2E。

## 2. HR Architecture Gate

Production禁止：
```text
8000作为第二默认A2A端口
fake cancel
employeeId from user text
execution_subject fallback parser
SnowHarness tenant/thread/invocation id
raw token logging
```

Contract cancel=false必须和Provider一致。

## 3. SnowHarness Architecture Gate

Production禁止：
```text
hr-assistant
8100
HR专用metadata
HR专用route resolver
HR专用runtime adapter
读取hr-agent-core源码
读取Provider Git SHA
```

SnowHarness只认识public contract facts。

## 4. Secret Audit

两仓扫描：
```text
Authorization: Bearer <real>
EMPLOYEE_IDENTITY_MAP_JSON实际值
EMPLOYEE_REF_SECRET实际值
HR_ASSISTANT_A2A_BEARER_TOKEN实际值
```

不得进入tracked file、snapshot、test report、log artifact。

## 5. Identity Audit

证明：
```text
SnowHarness
只拥有Principal subject

HR public layer
只收到opaque subject

HR private layer
完成subject→employee mapping
```

最终报告不得打印raw employeeId。测试可用假employeeId fixture。

## 6. Source Opacity Audit

SnowHarness production不存在：
- HR源码路径；
- HR依赖包；
- veADK；
- AgentKit SDK；
- HR Git信息。

真实联调只需contract file、endpoint、CredentialRef。

## 7. A2A Contract Audit

逐项冻结并列双方实现：
```text
AgentCard
message/stream
metadata
Task/context
input-required
message/send resume
cancel unsupported
Artifact result
```

## 8. Git Audit

两仓分别记录：
```text
HEAD
branch
git status
commits
changed files
```

并行临时branch/worktree必须已经合并到各自阶段2目标分支。

默认不push。

## 9. 最终报告

必须包含：
- Track H COMPLETE/BLOCKED + tests + live smoke；
- Track S COMPLETE/BLOCKED + Stage1 Gate + generic live integration + Web/Desktop；
- Join 12项真实E2E；
- none/bearer；
- identity；
- resume；
- cancel=false；
- stream failure；
- no HR special case；
- no source coupling；
- no secret leak。

## 10. 最终状态

只能：
```text
COMPLETE
```
或
```text
HARD_BLOCKED
```

COMPLETE含义：SnowHarness已用真实HR Agent证明通用黑盒Agent链成立，HR Agent也成为自洽外部A2A Provider，双仓无源码耦合和产品特例。
